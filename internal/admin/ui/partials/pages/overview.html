计费口径：费用按上游官方返回的 token 用量和已配置价格估算，价格依次取目标计费模板、全局模板和内置模型目录默认价，均未配置时按 0 计；金额已应用模型组系数（模型组扣费系数），是估算金额，不是厂商官方账单。系统不估算、不补算 token。客户端在上游返回用量前断开，或上游中途出错、超时、未返回最终用量时，该请求记为 0 token，日志标注“连接断开，未获取到计费字段”，因此统计可能少于厂商官方账单中这部分中断请求的用量。
完整计费与费用口径费用使用与额度扣费同源的估算金额，已含模型组系数（模型组扣费系数）；前端不再乘系数，也不反推未折算的配置基础价。用量不完整或费用不完整时显示为部分，不用零替代。
