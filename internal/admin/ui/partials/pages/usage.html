请求数按请求权重统计，不是记录数；补充用量记录权重为 0。未选模型组时汇总与客户端明细包含全部请求，选中模型组时只含成功请求（状态码 1–499）。模型组树始终为成功请求权重；模型明细优先取模型组明细，模型组明细为空时回退到按模型汇总，回退结果在未选模型组时含全部请求，选中模型组时为成功请求。本接口不能证明任意区间的成功率，因此不显示成功率。

计费口径：费用按上游官方返回的 token 用量和已配置价格估算，价格依次取目标计费模板、全局模板和内置模型目录默认价，均未配置时按 0 计；金额已应用模型组系数（模型组扣费系数），是估算金额，不是厂商官方账单。系统不估算、不补算 token，也不重放请求；上游未返回用量字段的请求不计 token、不计费。客户端在上游返回用量前断开，或上游中途出错、超时、未返回最终用量时，该请求记为 0 token，日志标注“连接断开，未获取到计费字段”，因此统计可能少于厂商官方账单中这部分中断请求的用量。
完整计费与费用口径 普通输入是 input_tokens，不含缓存读取和缓存写入。显式缓存读取是缓存读取的子集，推理是输出的子集；分期限缓存写与工具输入是独立字段，总 Token 才把普通输入、输出、缓存读取、缓存写入和工具输入相加，子集不重复相加或计费。费用使用与额度扣费同源的估算金额，已含模型组系数（模型组扣费系数）；前端不再乘系数，也不反推未折算的配置基础价。缺少可用价格时不补算费用。费用占比的分母是当前筛选的估算总费用。模型组树的请求数按成功请求加权，费用和 Token 统计全部已记录用量。费用占比在下列情况不可用：总费用为零或缺失，或用量、费用不完整；此时不推算。总费用与 Token 总量仍按已记录值展示（零显示 $0.00，缺失显示不可用），不补算。
