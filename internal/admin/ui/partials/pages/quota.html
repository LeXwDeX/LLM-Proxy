人员可用额度与已折算消耗

可用额度上限 模型组基数 × 职级系数 × 个人系数

模型组基数、职级系数、个人系数和模型组扣费系数均为正数时才生成正上限；任一为 0 时，该模型组在该周期显示“不限”。扣费系数不乘入上限公式，只用于已用费用折算一次；扣费系数为 0 时该组不限。未绑定职级或未加入模型组显示“未配置”，不按 0 或免费处理。

人员行的各周期进度是各独立限额组的合计，不是共享额度池；每个模型组的上限分别生效。展开明细可查看各组可用上限和各自的重置时间。

计费口径：费用按上游官方 token 用量和已配置价格估算，价格依次取目标计费模板、全局模板和内置模型目录默认价，均未配置时按 0 计。金额已应用模型组扣费系数（每次费用只折算一次），是估算金额，不是厂商官方账单；系统不估算 token，也不补算 token。30 天费用直接展示聚合接口 estimated_cost，不再次折算；返回 0 显示 $0.00，字段缺失或加载失败显示不可用。
