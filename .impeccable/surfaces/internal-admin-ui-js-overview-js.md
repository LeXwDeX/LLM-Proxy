# 首页总览

Mode: Operate. Scope: 管理后台首页及其只读数据接口，其他业务页保持现状。用户先读托管链路与所选区间的真实用量，再看目标健康、客户端/模型费用排行、需要关注的问题和最近变更；实时活动、双曲线、客户端表与旧历史统计退居下层辅助区。用户选择直接制作交互页面；已确认客户端表格仍是选中客户端后联动双曲线的对象选择控件。

## Direction contract

THESIS: 在同一工作面先回答“链路是否健康、所选区间用了多少、哪里异常”，再用实时曲线和客户端明细定位当前活动；不写入任何原型示意值。

OWN-WORLD: 沿用深蓝侧栏、浅色工作区、系统中文字体和现有按钮控件。总览使用托管链路横条、胶囊区间选择、五张区间卡片、健康/排行两列面板和关注/最近变更面板；实时活动保留原有指标带、双曲线与客户端表。并发峰值用柱状，输入/输出 Token 仍用不同颜色与线型的折线。

STORY: 操作者先读链路状态和区间数字，再切换 1 小时/今日/7 天/30 天；异常目标排在健康列表前面。点选客户端后，双曲线只切换到该客户端；全站数字保持全站范围。

FIRST VIEWPORT: 保留侧栏和顶栏。内容顶端为「总览」、刷新与实时活动更新时间；下方为托管链路横条、区间选择、区间卡片和目标健康。费用 Top 5、关注与最近变更紧随其后。实时活动、双曲线和客户端表位于辅助区，旧统计仍在底部折叠区。

FORM: 客户端联动的汇总—双曲线—明细工作面继续保留。区间切换只更新卡片和费用排行，不新增实时活动请求；刷新按钮重新读取概览、指标与聚合。手机纵向排布，链路和卡片两列，表格保留滚动容器。

## Data and states

- 托管链路只汇总已有值：`/admin/api/overview` 的 `client_count`、`targets`，`/admin/api/activity` 的当前在途/WS 会话与活跃客户端，`/admin/metrics` 的启动累计请求、运行时长、持久化积压和观察预算。缺失部分显示不可用，不推算。
- 区间卡片只使用 `/admin/api/overview` 的 `usage_summary`：`last_hour`、`today`（UTC 自然日）、`last_7_days`、`last_30_days`。只显示请求数、总 Token、输入/输出、预估费用和不完整计数。不显示任意区间成功率、失败/取消/重试、活跃客户端、缓存命中率、模型组折算费用、QPS 或延迟。显式 `0` 与缺失不同：缺失显示「不可用」，费用 `0` 显示 `$0.00`。
- 目标健康读取 `/admin/api/overview.targets` 的 `proxy.TargetStatus` JSON。顶层为 PascalCase，`Window15m` 内为 snake_case。排序为 muted、half-open、offline、ready 且存在密钥问题、正常、未知最后。展示 Phase、MutedUntil、在途/容量、15 分钟窗口和各 Key 状态汇总；单 Key 只说明目标级状态，零 Key 明确提示可能使用 Bearer/透传；不展示 Key 掩码、逐 Key 请求数、GLM 子类、目标成功率或端点 URL。
- 费用排行读取现有 `/admin/data/usage/aggregate?from=...&to=...&group_by=day`，范围与所选区间一致。客户端/模型各取前 5，按 `estimated_cost` 降序、`requests` 降序、名称升序。费用标注官方基础价，并说明按日桶边界聚合。缺失或被拒绝的聚合显示不可用，不显示零；`$0.00` 不能推断为免费或未定价。
- 需要关注只根据真实数据生成：异常目标、密钥问题、持久化积压/重试/丢弃、观察预算拒绝、当前区间不完整用量。没有可确认问题时显示「暂无需要关注的问题」，数据源缺失时明确标注部分不可用。
- 最近变更读取 `/admin/api/overview.recent_audit`，按时间倒序防御性排序，只渲染时间、操作者、动作、对象、结果五列，不渲染 `detail`。缺失与空数组区分显示。
- 新接口 `/admin/api/activity` 每 5 秒获取；历史概览、指标和聚合有 60 秒缓存，手动刷新强制重读。隐藏页面中止全部页面请求；恢复可见后重新加载。失败保留可解释的上次数据或明确不可用，不伪造零值。
- 并发曲线使用 `<rect class="activity-concurrency-bar">` 表示每个 10 秒桶的峰值；未知桶不画柱，不连接跨越缺口。Token 曲线保持折线。两图共享时间游标和读数。

解释长文统一收进信息图标，可悬停/聚焦/触屏查看；role=tooltip 不拦截下层命中，不含交互内容。安全沿用会话权限，不回显任何 keys。

## Validation and unresolved choices

桌面 1440×960 和手机 390×844 的检查覆盖：链路、区间切换、卡片缺失/零值、目标排序与单/零 Key 降级、Top 5 排序与错误态、关注措辞、最近变更无 detail、曲线柱状/折线、键盘读数、自动刷新暂停恢复和移动端无横向滚动。其中 `node --test internal/admin/ui/` 验证缺失/零值、错误态、键盘与暂停恢复，真实 `ui-sim` 验证链路、区间、健康、排行、关注、最近变更和移动端无横向滚动；两者都使用 fakellm，不调用真实模型。文档核对和 fakellm 验证不代表真实上游验收。
